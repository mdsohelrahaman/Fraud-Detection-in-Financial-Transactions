# Reports

Store generated evaluation tables and figures here when running the notebook locally.

Suggested outputs:
- `model_metrics.csv` — ROC-AUC, PR-AUC, precision, recall and F1 by model
- `confusion_matrix.png` — confusion matrix at the selected alert threshold
- `precision_recall_curve.png` — precision/recall trade-off
- `fraud_amount_distribution.png` — transaction amount distribution by fraud label
- `alert_summary.csv` — alert counts by severity
